# Product Context - Time Fomo

## Problem Statement
People lose track of time and miss important deadlines or events. They need visual reminders of time passing and upcoming commitments.

## Solution
Time Fomo provides multiple time visualization tools:
- Immediate awareness through countdown widgets
- Life perspective through hourglass visualization
- Event management with task tracking
- Proactive notifications for deadlines

## User Experience Goals

### Primary Users
- People who want to be more time-conscious
- Users who manage multiple deadlines
- Those seeking life perspective visualization

### Key User Flows
1. **Quick Time Check**: Glance at widget to see time remaining today
2. **Event Planning**: Create custom event, add tasks, get reminders
3. **Life Reflection**: View life hourglass to gain perspective
4. **Task Management**: Track progress on event-related tasks

### Design Principles
- Minimal interaction for maximum information
- Visual clarity with dark theme
- Instant access through widgets
- Non-intrusive but persistent reminders

## Product Differentiation
- Combines multiple time perspectives in one app
- Task integration with countdown events
- Life visualization unique feature
- Persistent alarms survive device reboots
- Clean, modern Material3 interface

## Success Metrics
- Widget usage frequency
- Task completion rates
- Alarm acknowledgment
- User retention through consistent widget updates
